# Efektywna i równoważna stopa procentowa
Część [[Matematyka finansowa]].

## Efektywna stopa (procentowa / dyskontowa)
- Oprocentowanie proste: ref(n) = r/(1 + (n-1)*r); def(n) = d/(1 - (n-1)*d)
- Złożone, kapitalizacja zgodna: ref = r; def = d
- Złożone, w podokresach: ref = (1 + r/m)^m - 1; def = 1 - (1 - d/m)^m
- Złożone, w nadokresach: ref = (1 + m*r)^(1/m) - 1; def = 1 - (1 - m*d)^(1/m)

## Równoważna stopa (procentowa / dyskontowa)
- Proste: r = d/(1 - n*d); d = r/(1 + n*r)
- Złożone, zgodna: r = d/(1 - d); d = r/(1 + r)

## Typy zadań (zajęcia 3)
- Efektywna stopa dla różnych kapitalizacji, także dyskontowych i 2-, 3-letnich (zad. 1).
- Równoważna intensywność oprocentowania (zad. 2).
- Nominalna stopa przy znanej efektywnej 4,8% i kapitalizacji kwartalnej (zad. 3).
- Czy dwie oferty są równoważne (półroczna 9% vs miesięczna 1,5%) (zad. 4).
- Ranking banków (w tym kapitalizacja ciągła) (zad. 5).
- Wybór najlepszego banku z kapitalizacją z dołu i z góry, kapitał po 9 latach (zad. 6).
- Zmiana kapitalizacji kwartalnej na półroczną, nowa stopa (zad. 7, 8).

## Dodatkowe wzory
- Nominalna z efektywnej: r = m*((1+ref)^(1/m) - 1)
- Intensywność oprocentowania: delta = LN(1 + ref)
