# Rachunek czasu
Część [[Matematyka finansowa]]. Zakres kolokwium: obliczanie czasu lokaty (liczba dni).

## Typy poleceń (Zestaw 1)
- Dokładna oraz przybliżona liczba dni między datami (zad. 1), np. 8.07.1999 i 16.03.2017; 31.12.2019 i 31.05.2023; 10.11.2015 i 31.10.2021.
- Liczba lat między datami "za pomocą znanych reguł" (zad. 2), np. 31.08.2003 i 15.06.2014; 27.01.2008 i 30.06.2016; 31.07.1985 i 31.08.2022.
- To samo funkcjami MS Excel (zad. 3).

## Reguły liczenia czasu (N w latach)
- dokładna: N = dokładna liczba dni / rzeczywista liczba dni w roku
- księgowa: N = dokładna liczba dni / 365
- przybliżona: N = przybliżona liczba dni / 365
- bankowa: N = dokładna liczba dni / 360
- zwykła: N = przybliżona liczba dni / 360

## Liczba dni
- Dokładna liczba dni = data końcowa - data początkowa (Excel: zwykłe odejmowanie).
- Przybliżona liczba dni = funkcja DNI.360.
